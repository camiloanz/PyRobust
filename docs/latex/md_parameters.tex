\hypertarget{md_parameters_autotoc_md22}{}\doxysection{$<$tt$>$failing\+\_\+type$<$/tt$>$}\label{md_parameters_autotoc_md22}
{\bfseries{Type\+:}} {\ttfamily str} or {\ttfamily tuple} ~\newline
 Defines the failure strategy applied during simulation. Possible values\+:


\begin{DoxyItemize}
\item {\ttfamily \char`\"{}random\char`\"{}} ~\newline
 Simulates random failure of nodes and/or edges.
\item {\ttfamily (\char`\"{}targeted\char`\"{}, metric\+\_\+name, mode)} ~\newline
 Applies targeted failure based on a centrality or ranking metric. ~\newline
 The {\ttfamily mode} defines how often the ranking is updated\+:
\begin{DoxyItemize}
\item {\ttfamily \char`\"{}static\char`\"{}} – ranking is computed once before the simulation
\item {\ttfamily \char`\"{}dynamic\char`\"{}} – ranking is re-\/evaluated after each failure step
\end{DoxyItemize}

See \mbox{\hyperlink{md_metrics}{metrics.md}} for a list of available metrics and which are compatible with targeted failure strategies.
\item {\ttfamily \char`\"{}epidemic\char`\"{}} ~\newline
 Simulates failure spreading from a randomly selected node to its neighbors.
\end{DoxyItemize}

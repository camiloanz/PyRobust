An open-\/source Python tool for evaluating network robustness using {\bfseries{robustness surface analysis}}.

Py\+Robust enables simulation of progressive node and edge failures to analyze how complex networks degrade under stress. The tool supports {\bfseries{random}}, {\bfseries{targeted}}, and {\bfseries{epidemic}} failure models and generates robustness surfaces that visualize how a network\textquotesingle{}s structural properties change under failure scenarios.

The main codebase is written entirely in Python. ~\newline
 Py\+Robust uses {\ttfamily igraph} as a high-\/performance backend for graph operations, while remaining fully compatible with {\bfseries{NetworkX}} for input and integration.

Users can add or modify metrics and failure models, as well as export results as CSV files or visual plots.
